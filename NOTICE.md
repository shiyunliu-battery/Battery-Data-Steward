# Notices

Battery Data Steward is an independent, vendor-neutral open-source toolkit for
battery data inspection, quality assurance, and reviewable preprocessing. It is
not affiliated with, endorsed by, or certified by any cycler vendor or standards
body. Validation of supported tables does not certify fitness for a particular
scientific analysis.

The project was previously named Battery Data Standard. Historical copyright
notices, Python module paths, exception names, and serialized format identifiers
remain valid and are retained for attribution and compatibility.
